# PHP PDO: Inserting Records and Getting Last Insert ID

This example demonstrates how to use PDO prepared statements to securely insert data into a MySQL database and retrieve the primary key generated by the database for that new record.

```php
<?php
// Database connection configuration
$dsn = 'mysql:host=localhost;dbname=test_db;charset=utf8mb4';
$user = 'db_user';
$pass = 'db_pass';

try {
    $pdo = new PDO($dsn, $user, $pass, [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

    // Prepare a secure SQL statement
    $sql = "INSERT INTO users (username, email) VALUES (:username, :email)";
    $stmt = $pdo->prepare($sql);

    // Execute the statement with input data
    $stmt->execute([
        ':username' => 'johndoe',
        ':email'    => 'john@example.com'
    ]);

    // Get the ID of the row that was just inserted
    $lastId = $pdo->lastInsertId();

    echo "New record created successfully. ID: " . $lastId;

} catch (PDOException $e) {
    echo "Error: " . $e->getMessage();
}
```

## Key takeaways
*   **Prepared Statements:** Always use placeholders (`:name`) to prevent SQL injection attacks.
*   **lastInsertId():** This method must be called on the PDO instance, not the statement object, to retrieve the auto-incremented ID.
*   **Error Handling:** Wrapping PDO operations in a `try-catch` block is essential for catching connection or query failures safely.
